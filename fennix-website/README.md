# FENNIX Medical website

Static site: `index.html` + `assets/`. No build step.

**Preview:** double-click `index.html`, or run `python3 -m http.server` in this folder and open http://localhost:8000.

**Deploy free on Netlify (easiest):** go to app.netlify.com/drop and drag this whole folder onto the page. Done.

**Deploy on GitHub Pages:** create a repo, upload these files, then Settings → Pages → Source: "Deploy from a branch" → main / root.

**Custom domain:** buy fennixmedical.com (or similar), then add it under Netlify "Domain settings" or GitHub Pages "Custom domain" and follow the DNS instructions they show.

**Before going public:**
